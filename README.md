# Проект ии-агента, узнающего у клиента информацию по заказу, в рамках соревнования "Код успеха".

> **Функционал**  
> - Собирает с клиента данные по проекту.
> - Руководствуется прайс-листом компании.
> - Старается решать возникающие конфликтные ситуации.
> - Формирует карточку проекта.

## Как работает приложение

<img src="etc\assets\graph.png" width="600" style="flex-shrink: 0;">


- Приложение работает на основе графа состояний, описанного через LangChain.
- У каждого пользователя - свое состояние графа.
- Состояние графа, грубо говоря - этап диалога.
- Принятие решений в диалоге происходит также в графе так, как это описано на схеме.
- Получение csv с прайс-листами происходит при помощи предоставления ИИ инструментария на определенных этапах графа.

### Сохранение карточки проекта

- После завершения диалога формируется карточка проекта.
- Реализовано хранение ВСЕХ карточек проекта в JSON формате. 

## Ручной запуск приложения

Для ручного развертывания среды приложения потребуется Docker.

Этапы развертывания:

- Склонируйте репозиторий
```
git clone https://github.com/child6yo/asu-cyberia-case
```

- Соберите приложение через docker compose
```
docker comopose up --build
```

- UI будет доступен по адресу localhost:80

## API REFERENCE 

### POST /api/chat - эндпоинт обращения к чат-боту

**Request body**

```
{
  "user_id": "string",
  "message": "string"
}
```

**200 Response body**

```
{
  "response": "string",
  "project": {
    ...
  }
}
```

### GET api/projects - эндпоинт выдачи всех собранных проектов

**200 Response body**

```
{
  "response": [
    {
      "name": "string",
      "customer": {
        "name": "string",
        "email": "string",
        "phone": "string"
      },
      "description": "string",
      "requirements": "string",
      "estimate": "string"
    }
  ]
}
```
